The hws library supports many different samples that can be collected. 
Two major design considerations were made when deciding on the supported samples. 
First, if a sample is supported by all hardware platforms, its name should be consistent across them. 
Note that there are samples that are not supported by all hardware platforms. 
In this case, the sample names were inspired by others available for all hardware platforms. 
Second, the used physical units should be the same regardless of the used hardware platform. 
For example, in the previous example in \autoref{code:vendor_library_calls}, the vendor-specific libraries report the total power consumption in $\si{\milli\joule}$ or $\si{\micro\joule}$. 
The hws library unifies the units such that the same unit is used across all hardware platforms. 
In the above example, the total power consumption is reported in $\si{\joule}$.
